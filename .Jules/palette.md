## 2024-05-22 - Form Error Association and Hydration Mismatches
**Learning:** Using manual string replacement (like `label?.toLowerCase().replace(/\s+/g, '-')`) to generate IDs for form inputs and their associated error/hint messages can cause Server-Side Rendering (SSR) hydration mismatches in Next.js (or React 18+ environments). Furthermore, visually associating errors below inputs without programmatic ARIA links leaves screen reader users unaware of the errors.
**Action:** Always use the `useId()` hook provided by React 18+ to generate stable, unique IDs. Use these IDs to set `aria-invalid={true}` and `aria-describedby={describedBy}` on the input element, pointing to the `id` attributes of the error and hint elements to ensure a fully accessible and hydration-safe form component.
