## 2026-05-27 - Input Component Accessibility and Hydration\n\n**Learning:** When generating IDs for accessibility attributes (like `aria-describedby` or labels) in React 18 / Next.js, relying on `Math.random()` or string replacement can cause SSR hydration mismatches. Additionally, setting `aria-describedby` to reference an element that hasn't rendered (like an empty error or hint span) causes screen readers to announce an empty reference.\n\n**Action:** Always use the React `useId()` hook to generate unique fallback IDs to ensure SSR stability. For `aria-describedby`, conditionally apply the reference IDs only when the target elements (error or hint messages) actually exist and are rendered.
