## 2026-05-14 - React Dashboard Table Filter Optimization
**Learning:** In React dashboards displaying fetched tables (like products or orders), client-side `.filter()` loops run on every re-render. If they use string conversions like `search.toLowerCase()`, it causes redundant string allocations on every iteration. Also, using inline fallback arrays `data?.items || []` busts `useMemo` caches because it creates a new array reference every time.
**Action:** Always wrap expensive or repetitive list-filtering operations with `useMemo`. Hoist loop-invariant string operations (e.g., `search.toLowerCase()`) outside the `.filter()` loop. Define a stable `const EMPTY_ARRAY = []` outside the component scope to use as a fallback, preserving referential equality during SWR/fetch loading states.
