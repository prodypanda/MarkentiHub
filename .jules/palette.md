## 2026-06-26 - Custom Upload Triggers Missing Keyboard Accessibility
**Learning:** Custom `div` elements used as upload triggers in this app (like in `ImageUploader.tsx`) often use `onClick` handlers but lack `role="button"`, `tabIndex`, and keyboard event handlers. This makes them inaccessible to keyboard users, who cannot trigger file dialogs without a mouse.
**Action:** When converting generic `div` containers into interactive upload buttons, always ensure they are fully keyboard accessible. Add `role="button"`, `tabIndex={0}` (or conditionally `-1` if disabled/loading), `aria-disabled` if applicable, and an `onKeyDown` handler to trigger the input file dialog on `Enter` or `Space` key presses. Also, ensure icon-only remove buttons within these components have explicit `aria-label` and `title` attributes.
