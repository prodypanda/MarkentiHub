## 2026-05-13 - Accessible Form Validation in Reusable Components
**Learning:** Reusable input components that conditionally render error or hint texts must deterministically connect these elements to the `<input>` via `aria-describedby` so screen readers announce them. If an ID is missing, `Math.random()` shouldn't be used due to SSR hydration mismatches; instead, React's `useId()` should generate a stable fallback ID. Additionally, setting `aria-invalid={true}` helps communicate to screen-reader users that the current input state is invalid.
**Action:** When building reusable UI inputs, always import `useId()`, generate unique IDs for helper texts, apply them to the conditionally rendered elements, and link them to the input using `aria-describedby` and `aria-invalid`.
